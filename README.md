# 📖 Sobre o Projeto

Sempre tive interesse em entender melhor como as ferramentas de Inteligência Artificial podem contribuir para o aprendizado e para a organização de informações. Aproveitando este desafio da DIO, decidi explorar o NotebookLM na prática para avaliar como a ferramenta pode apoiar a construção do conhecimento a partir de fontes confiáveis.

O tema escolhido para o estudo foi **Inteligência Artificial Generativa aplicada aos Negócios**, principalmente por ser uma tecnologia em constante crescimento no mercado e cada vez mais presente no ambiente corporativo.

Durante o projeto, utilizei o NotebookLM para analisar conteúdos de referência, criar resumos, comparar conceitos e testar diferentes abordagens de prompts, observando como pequenas mudanças nas perguntas podem impactar diretamente a qualidade das respostas obtidas.

---

# 🎯 Objetivos do Estudo

Antes de iniciar os testes, defini alguns objetivos para direcionar o aprendizado:

# 🔍 Testes de Prompts

Uma das partes mais interessantes do projeto foi perceber como pequenas alterações na forma de formular uma pergunta alteravam significativamente a qualidade das respostas.

## Experimento 1 – Pergunta Genérica

### Prompt

```text
Fale sobre Inteligência Artificial.
```

### Resultado

A resposta apresentou uma visão geral do tema, porém com pouco aprofundamento.

### Aprendizado

Perguntas muito amplas tendem a gerar respostas igualmente amplas e genéricas.

---

## Experimento 2 – Pergunta Contextualizada

### Prompt

```text
Explique como a Inteligência Artificial Generativa está transformando processos empresariais.
```

### Resultado

Foram apresentados exemplos relacionados à produtividade, automação e inovação.

### Aprendizado

Ao adicionar contexto à pergunta, as respostas ficaram mais alinhadas com o objetivo do estudo.

---

## Experimento 3 – Comparação Estruturada

### Prompt

```text
Compare Inteligência Artificial Tradicional e Inteligência Artificial Generativa em formato de tabela.
```

### Resultado

As informações foram apresentadas de maneira organizada, facilitando a comparação entre os conceitos.

### Aprendizado

Solicitar formatos específicos torna a informação mais fácil de interpretar e revisar posteriormente.

---

## Experimento 4 – Planejamento de Estudos

### Prompt

```text
Crie um plano de estudos de 30 dias para aprender Inteligência Artificial Generativa.
```

### Resultado

Foi gerado um cronograma com etapas progressivas de aprendizado.

### Aprendizado

Além de responder dúvidas, a IA também pode auxiliar na organização e planejamento dos estudos.

# ⚠️ Dificuldades Encontradas e Lições Aprendidas

Durante os testes, alguns desafios se destacaram.

## Respostas Muito Genéricas

### Problema

Perguntas sem contexto retornavam informações superficiais.

### Solução

Adicionar detalhes sobre o objetivo da pergunta e o cenário desejado.

### Aprendizado

Quanto maior o contexto fornecido, melhores tendem a ser os resultados.

---

## Respostas Muito Longas

### Problema

Algumas respostas dificultavam consultas rápidas.

### Solução

Solicitar resumos e limitar a quantidade de tópicos.

### Exemplo

```text
Resuma o conteúdo em até 5 tópicos principais.
```

### Aprendizado

Definir formato e tamanho ajuda a tornar o conteúdo mais objetivo.

---

## Necessidade de Validação

### Problema

Algumas respostas precisaram ser comparadas com as fontes originais.

### Aprendizado

A Inteligência Artificial é uma excelente ferramenta de apoio, mas não substitui a análise crítica das informações.

# 📘 Miniguia de Estudos

## O que é Inteligência Artificial Generativa?

A Inteligência Artificial Generativa é um ramo da IA capaz de criar novos conteúdos, como textos, imagens, códigos e outros formatos, com base em padrões aprendidos durante o treinamento dos modelos.

- Automação de respostas.

- Personalização de comunicação.

### Desenvolvimento de Software

- Geração de código;
- Documentação automática;
- Apoio em testes.

### Análise de Dados

- Resumos executivos;
- Identificação de padrões;
- Apoio à tomada de decisão.

# 📖 Glossário

### IA Generativa

Tecnologia capaz de criar novos conteúdos a partir de padrões aprendidos.

### LLM

Large Language Model. Modelo de linguagem treinado com grandes volumes de dados.

### Prompt

Comando ou instrução fornecida para uma Inteligência Artificial.

### Engenharia de Prompt

Técnica utilizada para elaborar perguntas e comandos mais eficientes.

### Hallucination

Situação em que a IA gera informações que parecem corretas, mas não possuem base factual.

### Fine-Tuning

Processo de ajuste de um modelo para atender necessidades específicas.

### RAG

Abordagem que combina recuperação de informações com geração de respostas.

### NotebookLM

Ferramenta do Google que utiliza documentos fornecidos pelo usuário como base para geração de respostas contextualizadas.

# 🚀 Prompts Reutilizáveis

## Para Resumos

```text
Resuma este conteúdo em até 10 tópicos principais.
```

## Para Revisão

```text
Explique este assunto como se eu estivesse estudando para uma prova.
```

## Para Aprofundamento

```text
Explique este conceito nos níveis básico, intermediário e avançado.
```

## Para Comparações

```text
Compare os conceitos apresentados utilizando uma tabela.
```

## Para Exercícios

```text
Crie 10 perguntas com respostas comentadas sobre este tema.
```

## Para Aplicação Prática

```text
Apresente exemplos reais de aplicação desse conceito em empresas.
```
